В работе выполняется сегментация потребителей леденцов на основе их оценок согласия с 11 высказываниями (V1–V11). Целью работы является определение оптимального числа кластеров, обоснование выбора и интерпретация результатов

Содержимое репозитория:
- `Python лаба1 Дубко А. В.ipynb` — основной ноутбук с кодом, визуализациями и выводами.
- `Леденцы.dat` — исходные данные.
- `README.md` — описание проекта.

Краткие результаты работы:
Было выбрано разбиение на 4 кластера. 
  1. «Лечебный» (108 чел.) — высокие оценки по V9 (боль в горле), V10 (заложенность носа) и V11 (улучшение самочувствия). Воспринимают леденцы как средство от простуды.
  2. «Свежее дыхание» (110 чел.) — высокие оценки по V1 (освежить дыхание), V2 (уверенность), V3 (освежить полость рта) и V4 (избавиться от неприятного вкуса). Воспринимают как средство гигиены.
  3. «Психологический» (59 чел.) — высокие оценки по V7 (сконцентрироваться) и V8 (отвлечься и подумать). Используют как способ снять стресс или сделать паузу.
  4. «Сладкоежки» (61 чел.) — высокие оценки по V5 (заменитель кондитерских изделий) и V6 (хочется сладкого). Воспринимают как вкусное лакомство и десерт.
